HOW TO RUN PROGRAM:

1. Download files from GitHub and extract to desired location
2. in the Software-Engineering-Team13 files, do $ chmod +x Script.sh
3. $ ./Script.sh
4. Let the script run and install all the files, the script will launch the UDP Server and game program together, then the splash screen will show and then in the terminal it will ask to choose a network, after choosing it will launch the player entry terminal
5. Follow the input, to enter the hardware ID, enter the codename and with the codename box still selected, press enter, to start the play action press F5 and to exit press F5 again or ESC.
